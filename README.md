# Idea ForgeX™

*by [Torvus](https://torvuslabs.com)*

Catch ideas for future AI prompts in seconds, even in the middle of other work. Claude scores each idea out of 100
and writes a prompt that's ready to run; one click opens it in a new Claude Code session. It runs on your own
computer, and your ideas stay there.

## Download

Get the latest version from **Releases** (on the right of this page):

| Your computer | Download |
|---|---|
| Windows 10 or 11 | `IdeaForgeX-1.0.4-windows.zip` |
| Mac with Apple silicon (M1 or newer), macOS 13+ | `IdeaForgeX-1.0.4-mac.zip` |

Then follow **QUICKSTART.pdf** (inside the download): install, turn on Claude, and save your first idea.

## What it does

- **Two-second capture:** type or dictate an idea and press Enter. Tags, projects and pasted lists work inline.
- **Scored by Claude:** value, ease, clarity and urgency, a 0–100 score, the reason, and the smallest next step.
  Possible duplicates and ideas waiting more than 3 weeks are flagged.
- **Ready-to-run prompts:** every idea gets a prompt with Goal, Context, What to build and Done when.
- **Run in Claude Code:** opens a new session in the Claude desktop app with the prompt filled in.
- **/xforge:** save ideas from inside any Claude Code session.
- **Your Claude, your data:** uses your own Claude Code (or an Anthropic API key). Ideas never leave your computer
  except the idea text Claude reads to score it.
